前端语言：JavaScript + Vue 单文件组件（.vue）
前端框架与构建:
H5: Vue 3 + Vite + Vant + Pinia
PC: Vue 3 + Vite + Element Plus + Pinia

后台管理前端: Vue 2 + Vue CLI + Element UI + Vuex
后端语言：Java（JDK 1.8）
后端框架与组件：Spring Boot 2.7.x + Maven 多模块工程 + MyBatis-Plus + Redis（Redisson/JetCache） + MySQL

前端功能：
账号与安全：注册登录、找回密码、实名认证、安全验证
行情中心：多市场行情、自选、搜索、详情
交易中心：现货、合约（永续/交割）、期权、多品类交易
订单记录：当前委托、历史委托、成交与订单明细
资产资金：资产总览、充值提现、账变流水、兑换、收款/银行卡管理
C2C交易：买卖币、支付、申诉、聊天
跟单系统：交易员列表、跟随设置、我的跟单、申请交易员
理财增值：基金/矿机/锁仓、质押借币、收益与订单
内容与运营：公告新闻、帮助中心、关于与协议
扩展业务：NFT、新股申购、IEO、推广、AI助手、钱包连接

平台与权限：用户、角色、菜单、日志、系统参数与开关
用户与风控：用户资料、推荐关系、认证审核、安全项、风险用户
资金与费率：充值、提现、资金流水、费率配置
交易与订单：现货、合约、杠杆、期权、外汇/商品/股票订单
C2C与跟单：广告、订单、申诉、收款方式、银行卡、交易员跟单体系
