产品概述
壹信 IM 由“壹软团队”开发，定位为一套全平台、高并发、私有化的即时通讯解决方案。产品特点如下：
全栈源码交付：提供 iOS、Android、Web、PC（Windows/macOS）及后台管理的完整源码。
技术栈先进：客户端采用 Flutter 3.x，服务端使用 Go 语言，后台管理基于 Vue 3。
高并发架构：专为大规模在线场景设计，支持水平扩展。

技术架构
壹信 IM 的技术架构以高并发和可靠性为核心：
核心语言与框架：
服务端：Go 1.24 + Gin + GORM + Gorilla WebSocket
客户端：Flutter / Dart
管理后台：Vue 3.5 + TypeScript 5.6 + Vite
数据与基础设施：MySQL 8、MongoDB 7、Redis 7，支持 Docker Compose 部署。
音视频能力：集成 Agora RTC 与 LiveKit，支持 WebRTC。
推送通道：覆盖 Apple APNs、Firebase FCM、华为、小米、OPPO 及 Web Push。
核心架构能力包括：
分片式实时连接中心：将用户连接与会话订阅拆分到独立分片，支持多设备连接。
顺序可靠的消息系统：以服务端持久化的 Seq 序号为准，保证消息顺序。
持久化 Outbox 投递：将消息事件拆分为可恢复任务，支持重试与死信处理。
Redis 异步任务队列：分工处理缓存、在线状态、消息序号等任务。
多存储职责分离：MySQL（用户/会话等）、MongoDB（消息正文）、Redis（缓存/队列）。

功能模块
壹信 IM 功能完善，覆盖主流社交与IM场景。

1. 客户端功能 (IM App)
即时通讯：单聊、群聊、频道，支持消息回执、撤回、转发、引用、编辑。群聊支持万人大群、群公告、@全体成员、定时消息等。
朋友圈动态：支持图文/视频发布、点赞、评论、话题标签。
音视频通话 (RTC)：高清低延迟，支持 CallKit、通话状态恢复、视频转语音。
钱包与商业化：内置支付路由，支持红包（拼手气/普通）、转账、VIP 会员体系。
账号与安全：多方式注册登录、双Token刷新、设备管理、两步验证、端到端加密。

2. 后台管理系统 (Web Admin)
数据与用户管控：全局运营看板、用户画像、一键拉黑/封禁。
会话与内容净化：群组管理、全域消息溯源、违禁词库、投诉受理。
财务流转：资金账户管理、提现/充值工单、对接微信/支付宝。
系统运维：自动容量评估、服务监控、API限流、推送证书管理。
客服工作台：实时接待、会话转接、快捷回复、知识库、数据报表。

部署与性能
部署方式：支持 Docker 单机部署，也可按需拆分为多节点集群。
压测数据：在阿里云 8 核 16G、10M 带宽环境下，完成 20,000 并发 专项压测，成功率 99.26%。
容量预估：基于压测表现，单机 8 核 16G 预计可稳定承载 5-8 万长连接。
数据所有权：客户独立掌控数据、域名、证书和对象存储。
